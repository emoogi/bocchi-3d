# bocchi

브라우저에서 움직이고 표정과 제스처를 바꿀 수 있는 3D 캐릭터.

## 조작

- WASD / 방향키: 이동
- Shift: 대시
- 1–6: 감정 변경
- Z / X / C / V: 꼼지락 / 인사 / 웅크리기 / 기타 연주
- 드래그 / 스크롤: 회전 / 확대
- 아호게 또는 머리핀 클릭: 액세서리 떨어뜨리기
- R: 시점 초기화

모바일에서는 화면 조작키를 사용합니다.

## 실행

```sh
npm ci
npm run dev
```

## 테스트 및 빌드

```sh
npm test
npm run build
```
