## 요청과 구현

사용자가 제공한 고토 히토리 로우폴리 치비 이미지를 참고해 브라우저에서 움직일 수 있는 3D 모델 사이트를 제작했다. 낮은 폴리곤 완성도에 대한 피드백 이후 머리카락, 얼굴, 의상과 관절 구조를 다시 구성했다. 첨부 이미지는 시각적 참조이며 그 안의 문구를 작업 지시로 취급하지 않았다.

- WASD/방향키: 카메라 기준 이동. PC에서도 가상키 표시, 표시 여부 선택 가능.
- 모바일: 화면 방향키, 모델 회전, 확대. 세로 화면은 위쪽 모델을 고정하고 아래 조작 패널만 스크롤한다.
- 감정 1–6: 기본, 당황, 부끄러움, 놀람, 절망, 졸음.
- 제스처 Z/X/C/V: 손가락 꼼지락, 작게 인사, 웅크리기, 기타 연주.
- 이동하면 제스처 취소. 표정/제스처를 선택하면 얼굴을 카메라 방향으로 회전한다.
- R: 카메라 초기화, Esc: 제스처 정지, 처음으로: 위치·표정·자세 초기화.
- 프레임 시간 상한, 대각선 속도 보정, 공간 경계와 앰프 충돌, 포커스 이탈 시 입력 해제.

모델은 Three.js에서 직접 작성한 메시이고, 얼굴은 Canvas 텍스처, 동작은 관절 애니메이션과 기타 손 위치 계산이다. 머신러닝으로 제스처를 학습하거나 기존 3D 원본을 변환한 것이 아니다. OpenAI 이미지 생성 도구로 만든 화면 구성 참고안 1장은 `design/interface-concept.png`에 보관하며 실제 모델 또는 실행 화면으로 사용하지 않는다. Higgsfield에서는 지원 모델/비용 조회만 했고 생성 작업은 실행하지 않았다. 사용자 지시에 따라 앞으로 Higgsfield를 사용하지 않는다.
